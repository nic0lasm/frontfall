# Maps

Every map in Frontfall is generated by a script in this repository: the
Earth maps from public-domain geographic data, the city maps from satellite
land cover and elevation, and three small test maps from shapes drawn in
their definitions. Nothing is copied from another
game. The file layout is specified in
[`map-format.md`](map-format.md).

| Map      | Size        | Topology                              | Nations | Players (min / recommended / max) |
| -------- | ----------- | ------------------------------------- | ------- | --------------------------------- |
| World    | 2048 × 1024 | Cylinder, wraps east to west          | 70      | 2 / 24 / 64                       |
| Europe   | 1280 × 1080 | Flat, 25° W to 45° E, 33° to 72° N    | 40      | 2 / 12 / 32                       |
| Americas | 960 × 1024  | Flat, 170° W to 30° W, 57° S to 75° N | 28      | 2 / 10 / 22                       |
| Africa   | 1024 × 1024 | Flat, 20° W to 56° E, 36° S to 38° N  | 32      | 2 / 12 / 32                       |
| Asia     | 1280 × 1088 | Flat, 25° E to 150° E, 12° S to 78° N | 40      | 2 / 14 / 40                       |
| Island   | 256 × 192   | Flat, drawn                           | 6       | 2 / 4 / 8                         |
| Strait   | 320 × 192   | Flat, drawn                           | 6       | 2 / 4 / 8                         |
| Ring     | 512 × 256   | Cylinder, drawn                       | 6       | 2 / 6 / 8                         |
| Paris    | 768 × 440   | Flat, 2.215° E to 2.475° E, city      | 37      | 2 / 12 / 32                       |
| Lyon     | 780 × 532   | Flat, 4.765° E to 4.995° E, city      | 19      | 2 / 10 / 19                       |

The catalogue `maps/index.json` lists each map with a `group` the menu shows
apart: `world` for the maps of the Earth, `quick` for the drawn ones. A
definition sets it with `"group"`, `world` by default.

The three drawn maps are small and quick to play, and each exercises one
case: a single landmass, two continents joined only across a four-tile
strait, and a belt of land that crosses the east-west seam.

Player counts are first estimates from the map size and the number of
nations, not yet checked in played games; playtests will adjust them.

## Building the maps

```sh
pnpm maps            # downloads the sources once, then rebuilds every map
pnpm maps --check    # same, but fails if a map changed without a new version
```

The generated files are committed in `apps/client/public/maps/`, so the game,
the tests and the container build never need the network. `pnpm maps`
rebuilds them byte for byte: two runs on two machines give the same files,
and CI checks it on every change to the generator or to a map definition.
Thumbnails are the one exception: their compressed bytes depend on the zlib
build inside Node.js, so the generator compares decoded pixels and leaves a
committed thumbnail untouched when its image is the same.

Sources are downloaded into `node_modules/.cache/mapgen/` (or the folder in
`FRONTFALL_MAP_CACHE`) and are never committed. Each one is pinned by URL and
SHA-256 in [`tools/mapgen/sources.json`](../tools/mapgen/sources.json): a
file whose checksum differs is refused, so an upstream change can never alter
a map silently.

### Why the generated files are committed

The World terrain file is 2 MB raw and about 130 kB compressed, Europe 1.4 MB
and about 55 kB, and git stores them compressed. In exchange, a fresh clone
plays offline, the container build needs no download, and every change to a
map shows up in review. A map only changes when its version is bumped, so the
history grows by one such file per published version.

## Sources

All layers come from [Natural Earth](https://www.naturalearthdata.com/)
version 5.1.2, at 1:10 million scale, as published in the
[natural-earth-vector](https://github.com/nvkelso/natural-earth-vector)
repository. Natural Earth is in the public domain.

| Layer                                         | Used for                               |
| --------------------------------------------- | -------------------------------------- |
| `ne_10m_land`                                 | Land and water                         |
| `ne_10m_lakes`                                | Lakes cut out of the land              |
| `ne_10m_glaciated_areas`                      | Impassable ice (Greenland, glaciers)   |
| `ne_10m_geography_regions_polys`              | Mountain ranges, plateaus, foothills   |
| `ne_10m_geography_regions_elevation_points`   | Summit heights, to grade the ranges    |
| `ne_10m_bathymetry_K_200`, `I_2000`, `G_4000` | Water depth                            |
| `ne_10m_populated_places_simple`              | Capitals, for the starting nations     |
| `ne_110m_admin_0_countries`                   | Population and outline of each country |

## How a map is made

A map definition in [`tools/mapgen/definitions/`](../tools/mapgen/definitions)
gives the id, names, version, size, topology, bounds and a few thresholds.
The generator ([`tools/src/mapgen/`](../tools/src/mapgen)) then:

1. **Rasterises** the land polygons onto the grid: a tile is land when its
   centre lies inside a land polygon (even-odd rule, so holes such as the
   Caspian Sea stay water). Lakes are cut out the same way. Columns are evenly
   spaced in longitude and rows in latitude. Only additions, multiplications
   and divisions are used, so the result is identical on every machine.
2. **Opens the straits** listed in
   [`tools/mapgen/straits.json`](../tools/mapgen/straits.json): waterways
   narrower than a tile, such as the Bosporus and the Dardanelles, would
   otherwise cut the Black Sea off from the ocean (R-MAP-05). Each is a path
   of points carved as a one-tile channel. Seas left enclosed on purpose,
   such as the Caspian, the Aral Sea and Lake Balkhash, stay lakes. The
   Panama and Suez canals are missing from Natural Earth's coastlines, so
   they are carved the same way, the Suez Canal together with the Gulf of
   Suez, which is too narrow on the World map to reach the Red Sea.
3. **Cleans the coast**: islands and lakes smaller than `minIslandTiles` and
   `minLakeTiles` are removed, except where they touch the edge of a flat map
   and continue beyond it.
4. **Adds relief and depth** (see below).
5. **Freezes the poles**: land on a glacier, or beyond the `ice` latitudes of
   the definition, becomes impassable (R-MAP-02). On the World map, that is
   north of 80° N and south of 60° S, which covers Antarctica.
6. **Marks the shore**: the shore bit is set on land tiles with a water
   neighbour, across the seam on a cylinder.
7. **Places nations**, one per country, at its capital moved to the nearest
   tile a player can own (at most 12 tiles away). Nations are chosen one at a
   time until `nations.count` are placed. The next pick is the country with
   the best score: the fourth root of its population times its ownable land
   on this map, times its distance to the nations already placed, counted up
   to three times `nations.minDistance`. No two nations start closer than
   `nations.minDistance`. Large countries come first, and a crowded region
   gives way to an emptier one once it holds a few nations. The manifest
   lists nations in pick order, so its first n nations are spread as well as
   n can be.

   A definition can also list `nations.seats`: places of Natural Earth, by
   name and country code, that always hold a nation and are placed before
   the countries are picked. A seat with `region` set is named after its
   region, Natural Earth's first-level division; otherwise after its
   country. Seats share out land that one country would otherwise have to
   itself: with Ottawa as the only start north of the United States, Canada
   won 18 games of nations out of 24 on World, with the whole Arctic free to
   take. World and Americas therefore seat Greenland (Nuuk), Nunavut
   (Iqaluit), the Northwest Territories (Yellowknife), Yukon (Whitehorse)
   and Alaska, World also Iceland, and Americas Chubut (Rawson), whose
   Patagonia Argentina had to itself once Canada was held back. Alaska
   starts from Anchorage, its largest city, rather than from its capital:
   Juneau lies too close to Whitehorse for both to hold a nation.

   On a continent map, `nations.continents` limits nations to the countries
   Natural Earth places on those continents, and `nations.alsoCountries`
   adds others by code: Asia takes Asian countries and Russia, so Egypt or
   Ukraine never start there even though their land is on the map.
   `nations.edgeMargin` keeps every start that many tiles from the edges of a
   flat map. The build fails when fewer than `nations.count` nations can be
   placed, and `players.max` never exceeds that count on a continent map.

8. **Writes** the terrain file, a 256-pixel-wide thumbnail, the manifest with
   the terrain's SHA-256, and `index.json`, the list of maps for the menu.

### The east-west seam

On a cylinder, the first column starts at 180° W and the last one ends at
180° E, so both are sampled from neighbouring longitude bands and nothing
special happens at the seam. Natural Earth splits polygons that cross the
date line, such as Chukotka or Fiji, and each half fills its own side. A test
checks that column 0 and the last column differ no more than the most
different pair of neighbouring columns elsewhere on the map.

### Relief and depth

Natural Earth has no elevation grid, so relief comes from its named physical
regions. Elevation and bathymetry rasters such as NOAA ETOPO would be more
detailed; they can replace this step later without changing the format.

| Land band | Source                                                                                |
| --------- | ------------------------------------------------------------------------------------- |
| 0         | Everything else: plains                                                               |
| 10        | Plateaus and foothills                                                                |
| 13        | Ranges whose highest listed summit is under 1,500 m, or minor ranges without a summit |
| 20        | Ranges with a summit from 1,500 m, or major ranges without one                        |
| 24        | Ranges with a summit from 2,500 m                                                     |
| 28        | Ranges with a summit from 4,000 m                                                     |
| 31        | Glaciers and land beyond the ice latitudes                                            |

When regions overlap, the higher band wins. The engine reads 10 to 19 as
hills and 20 to 30 as mountains.

| Water band | Depth             |
| ---------- | ----------------- |
| 0          | Less than 200 m   |
| 8          | 200 to 2,000 m    |
| 16         | 2,000 to 4,000 m  |
| 24         | More than 4,000 m |

## City maps

Paris and Lyon cover a few kilometres each: a tile is about 25 metres wide in
Paris and 23 in Lyon. At that scale Natural Earth draws a whole river as a
single line, so a definition with a `city` object is built from two rasters
listed under `rasters` in `tools/mapgen/sources.json`, pinned by SHA-256 like
the other sources:

| Raster                                                                 | Used for                      | License                                       |
| ---------------------------------------------------------------------- | ----------------------------- | --------------------------------------------- |
| [ESA WorldCover 10 m 2021 v200](https://esa-worldcover.org/), 3° tiles | Open water and tree cover     | CC BY 4.0                                     |
| Copernicus DEM GLO-30, 1° tiles                                        | Elevation, one value per 30 m | Copernicus DEM GLO-30 licence, free of charge |

Both are read from their public buckets on Amazon S3; the generator reads only
the window a map covers. OpenStreetMap would draw the rivers and parks as
outlines, but it was out of reach of the build machines; the land cover's 10 m
pixels draw the Seine and the Rhône just as recognisably at this scale.

The generator ([`city.ts`](../tools/src/mapgen/city.ts)) then:

1. **Counts the land cover pixels** whose centre lies in each tile. A tile is
   water when at least `waterShare` of them are open water, and woods when at
   least `woodsShare` are tree cover.
2. **Mends the rivers**: bridges count as built-up land, so water is grown by
   `bridgeTiles` tiles and shrunk back by as many, which closes every gap
   that narrow. `widenTiles` then grows it further, so a river ships can sail
   is never a single tile wide; Paris widens the Seine by one tile.
3. **Cleans the coast** as on the other maps, and drops woods smaller than
   `minWoodsTiles`: a tree-lined avenue is not a wood.
4. **Raises the hills**: the elevation, read at each tile's centre, is
   replaced by the median of the tiles `smoothTiles` around it. The
   Copernicus DEM is a surface model, so it includes buildings; the median
   keeps Montmartre and drops the Part-Dieu tower. Land from `hills` metres is
   hills (band 13), from `mountains` metres mountains (band 20). Woods below
   that are band 10, so they cost an attacker what hills do.
5. **Places the landmarks** listed in `city.landmarks` (R-LAND-01) on the
   nearest land a player can own, and writes them into the manifest. Paris
   has the Louvre (gold), the Parc des Princes (growth), Sacré-Cœur
   (fortress), the Eiffel Tower (shield) and the Arc de Triomphe (assault);
   Lyon has Le Crayon, the Part-Dieu tower (gold), the OL stadium in
   Décines (growth), Fourvière Basilica (fortress) and the Port
   Édouard-Herriot (trade). Lyon reaches east to Décines for its stadium.
6. **Places nations** at the points listed in `city.nations`, in the order
   written, as on a drawn map: the arrondissements and quarters of the city
   and the towns around it, each at its town hall. Paris seats the inner
   suburbs too: with the arrondissements alone, the outskirts were free to
   take, and a player starting there won 10 games out of 12 against normal
   nations (`pnpm balance -- --map paris --bots normal:4 --nations normal
--average`). With 37 nations and hills from 48 m, it wins 8 of 24, about
   what it wins on World. Lyon seats 19 nations: with 18 it won 11 of 24, with
   19 and hills from 225 m, 5 of 24.

The manifest credits both rasters, and the about page and
[CREDITS.md](../CREDITS.md) carry the attributions their licences ask for.

## Versions and checks

[`tools/mapgen/published.json`](../tools/mapgen/published.json) records the
SHA-256 of every published version of every map. `pnpm maps` adds the new
versions it builds; `pnpm maps --check` fails when a definition builds bytes
that differ from what its version was published with. Changing a threshold,
the generator or a source therefore needs a new `version` in the definitions
it affects.

`pnpm maps --check` also measures how long the engine takes to load each map
and fails above 100 ms. CI runs it whenever `tools/mapgen`,
`tools/src/mapgen` or the map files change, then checks that the rebuilt
files are identical to the committed ones.

The tests in [`tools/test/published-maps.test.ts`](../tools/test/published-maps.test.ts)
check every committed map: manifest and checksum, the seam, ice beyond the
polar limits, every nation on land a player can own, the Himalayas, the Andes
and the Alps among the mountains, the Black Sea, the Sea of Azov, the Baltic
and the Mediterranean reachable from the ocean, short sea routes through
the Panama and Suez canals, thumbnails under 40 kB.

## Adding a map

1. Add a definition in `tools/mapgen/definitions/<id>.json`, starting from
   `europe.json` for a region.
2. Run `pnpm maps` and look at `apps/client/public/maps/<id>.png`.
3. Commit the definition, the generated files and `published.json`, and add
   the map to the table above.

A drawn map adds a `drawn` object to its definition: `land` and `mountains`
polygons as rings of `[lon, lat]` points, and `nations` with a name, a capital
and a point. Nations keep the order written and start on the nearest land a
player can own. Its manifest credits the project instead of a dataset.

Bounds are in degrees. For a regional map, choose the size so that a tile
covers about the same distance east-west as north-south at the middle
latitude: `width / height ≈ (east − west) × cos(latitude) / (north − south)`.
