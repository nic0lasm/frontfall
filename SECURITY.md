# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/nic0lasm/frontfall/security/advisories/new). Do not open a public issue.

Include what you found, how to reproduce it, and its impact as you see it. You will get an acknowledgement within 72 hours and a first assessment within 7 days. Once a fix is released, the advisory is published and you are credited unless you prefer otherwise.

## Scope

In scope: the code in this repository and the official server at `nclsmgr.com/frontfall`.

Out of scope: denial of service by volume, social engineering, and findings that need a compromised device.

## Supported versions

Only the latest release and the `main` branch receive security fixes.
